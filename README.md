# Zenit Alanya Site

Отдельный статический сайт футбольной школы Zenit Alanya.

## Структура

- `index.html` — главная
- `history.html` — история и достижения
- `training.html` — группы, расписание и стоимость
- `team.html` — тренерский штаб
- `match.html` — публичный матч-центр и защищённая панель администратора
- `contacts.html` — контакты и запись через WhatsApp
- `styles.css` — адаптивный дизайн и анимации
- `script.js` — русский/турецкий языки и интерактивные элементы
- `match.js` — счёт, состав, семь схем, события и лучший игрок матча

Матч-центр синхронизируется через отдельный проект Supabase. Публичным посетителям доступно только чтение; изменения разрешены только подтверждённой учётной записи администратора.

Расписание и стоимость в текущей версии помечены как предварительные данные.
