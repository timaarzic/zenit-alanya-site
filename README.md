# Zenit Alanya Site

Отдельный статический сайт футбольной школы Zenit Alanya.

## Структура

- `dist/index.html` — главная
- `dist/history.html` — история и достижения
- `dist/training.html` — группы, расписание и стоимость
- `dist/team.html` — тренерский штаб
- `dist/match.html` — публичный матч-центр и защищённая панель администратора
- `dist/contacts.html` — контакты и запись через WhatsApp
- `dist/styles.css` — адаптивный дизайн и анимации
- `dist/script.js` — русский/турецкий языки и интерактивные элементы
- `dist/match.js` — счёт, состав, семь схем, события и лучший игрок матча

Матч-центр синхронизируется через отдельный проект Supabase. Публичным посетителям доступно только чтение; изменения разрешены только подтверждённой учётной записи администратора.

Расписание и стоимость в текущей версии помечены как предварительные данные.
