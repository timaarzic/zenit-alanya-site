# Zenit Alanya Site

Отдельный статический сайт футбольной школы Zenit Alanya.

## Структура

- `index.html` — главная
- `history.html` — история и достижения
- `training.html` — группы, расписание и стоимость
- `team.html` — тренерский штаб
- `match.html` — публичный матч-центр и защищённая панель администратора
- `contacts.html` — контакты и запись через WhatsApp
- `styles.css` — адаптивный дизайн и анимации
- `script.js` — русский/турецкий языки и интерактивные элементы
- `match.js` — счёт, состав, семь схем, события и лучший игрок матча
- `match-config.js` — публичные настройки подключения матч-центра
- `icons.svg` — набор иконок
- `assets/` — изображения логотипа

## Как заменить файлы в GitHub

1. Распакуйте архив на компьютере.
2. Откройте только https://github.com/timaarzic/zenit-alanya-site.
3. В корне репозитория выберите **Add file → Upload files**.
4. Перетащите все файлы и папки из распакованного архива, включая `assets/` и `scripts/`. Сам ZIP и внешнюю папку архива загружать не нужно. `index.html` должен находиться в корне репозитория.
5. Сохраните изменения кнопкой **Commit changes** в ветку `main`. Файлы с одинаковыми именами заменятся; предварительно удалять весь старый сайт не нужно.
6. Отдельно удалите старый `head-coach-andrey-arkhipenko.jpg` в корне репозитория: откройте файл, выберите **Delete file**, затем **Commit changes**. Он не входит в новую публичную версию. Это удаление убирает файл из текущей версии, но не из истории Git.
7. Дождитесь успешного завершения **Actions → pages build and deployment**, затем откройте https://timaarzic.github.io/zenit-alanya-site/ и обновите страницу.

GitHub Pages уже включён в этом репозитории. Проверка автоматической публикации выполнена по последним успешным запускам; новую ручную загрузку нужно проверить после её сохранения. Публикация GitHub Pages и публикация Vercel — отдельные операции. Сайт https://zenit-alanya.vercel.app/ уже обновлён до той же версии интерфейса.

Настроенный проект Supabase сохраняется. Данные матчей, серверная проверка пароля и фотографии, добавленные в матч-центре, хранятся отдельно от этих файлов; пересоздавать или удалять базу для этой замены не требуется.

Матч-центр синхронизируется через отдельный проект Supabase. Публичным посетителям доступно только чтение. Изменения проходят через серверную Edge Function с проверкой пароля и короткоживущей защищённой сессией; пароль и серверный ключ не попадают в публичный код.

Публичная версия: https://zenit-alanya.vercel.app/

Репозиторий сайта: https://github.com/timaarzic/zenit-alanya-site

Подготовлена адаптивная ревизия от 14 октября 2026: карточки главного экрана в обычной сетке без наложения на эмблему, защита подписей игроков от обрезания, прокрутка футбольного поля на сенсорных экранах, комфортные поля ввода iOS, устойчивое меню и пересчёт высоты раскрытых ответов при смене языка или ориентации. Исправлены обозначение гола в протоколе, расположение значка площадки, маркеры хронологии и фон зарезервированного фото тренера.

Расписание и стоимость в текущей версии помечены как предварительные данные.

## Проверка интерфейса

`npm ci && npm test` запускает офлайн-проверки всех шести страниц, переключения RU/TR, меню, трёх возрастных расписаний, FAQ и матч-центра с подставными ответами API. Отдельно проверяются CSS-правила для ширин 320–1920 px. Настоящий пароль и база данных в этих тестах не используются; физические устройства и реальную авторизацию они не заменяют.
